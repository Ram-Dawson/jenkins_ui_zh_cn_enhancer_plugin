Git hooks允许在发生某些重要的 Git 仓库操作时调用脚本。 此配置控制 Jenkins 控制器 上客户端钩子的执行。 建议在控制器上 禁用 Git 钩子。

Jenkins 控制器使用 Git 仓库来检出 Pipeline 定义、检测远程仓库中的更改以及缓存 Pipeline 共享库。 在控制器上运行的 Jenkins 作业可以通过许多其他方式使用 Git 仓库。 强烈建议不要在 Jenkins 控制器上运行作业。 有关更多详细信息，请参阅 控制器隔离文档 。

克隆仓库时，客户端钩子不会被复制。 但是，客户端钩子可能会通过构建步骤或错误配置安装在仓库中。

如果控制器上允许挂钩脚本，则当执行匹配的 Git 操作时，将执行安装在 Jenkins 控制器仓库中的客户端钩子脚本。 例如，如果控制器上允许挂钩，并且控制器上的 Git 仓库包含 post-checkout 挂钩，则在该仓库中进行任何检出后，挂钩脚本将在控制器上运行。 如果控制器上允许挂钩，并且控制器上的 Git 仓库包含 pre-auto-gc 挂钩，则挂钩脚本将在任何自动 git 垃圾收集任务之前在控制器上运行。

有关 Git 仓库钩子的更多详细信息，请参阅 “自定义 Git - Git 挂钩”。
