git 步骤会将指定仓库克隆到 Pipeline 工作区。

使用Pipeline 语法片段生成器为 Git 步骤生成示例 Pipeline 脚本。 更高级的检出操作需要使用 scmGit 参数的 checkout 步骤而不是 git 步骤。 git 步骤的示例包括：

  • 使用默认值的 Git 步骤
  • 使用 https 和特定分支的 Git 步骤
  • 使用 ssh 和私钥凭证的 Git 步骤
  • 禁用 https 和变更日志的 Git 步骤
  • 禁用 Git 协议和轮询的 Git 步骤
请参阅参数描述了解更多详情。

git 步骤是功能更强大的checkout 步骤及其 scmGit 参数的简化写法： 

checkout scmGit(branches: [[name: 'main']],
    userRemoteConfigs: [[url: 'https://git-server/user/repository.git']])

笔记：这checkout 步骤与 scmGit 参数是首选 SCM 检出方式。 它提供了比 git 步骤更多的功能。

使用Pipeline 语法片段生成器为检出步骤生成示例 Pipeline 脚本。

这checkout 步骤与 scmGit 参数可以在许多无法使用 git 步骤的情况下使用。 请参阅Git 插件文档有关可用选项的详细说明checkout 步骤的 scmGit 参数。 例如， git 步骤确实不是支持：

  • SHA-1 检出
  • 标签检出
  • 子模块检出
  • 检出稀疏
  • 大文件检出 (LFS)
  • 参考仓库
  • 分支合并
  • 仓库标记
  • 自定义 refspec
  • 超时配置
  • 针对非默认参考的变更日志计算
  • 枯枝修剪

示例：使用默认值的 Git 步骤

使用 https 协议、无凭据和 master 分支从 Git 插件源仓库检出。

这Pipeline 语法片段生成器生成这个例子： 

git 'https://github.com/jenkinsci/git-plugin.git'

示例：使用 https 和特定分支的 Git 步骤

使用 https 协议、无凭据和特定分支 (stable-2.492) 从 Jenkins 源仓库检出。 请注意，这必须是本地分支名称，例如“master”或“develop”。

git 步骤不支持的分支名称

  • 远程分支名称如“origin/master”和“origin/develop”是不支持作为分支参数
  • SHA-1 哈希值是不支持作为分支参数
  • 标签名称是不支持作为分支参数

远程分支名称、SHA-1 哈希值和标签名称受到支持按通用目的checkout 步骤的 scmGit 参数.

这Pipeline 语法片段生成器生成这个例子： 

git branch: 'stable-2.492',
    url: 'https://github.com/jenkinsci/jenkins.git'

示例：使用 ssh 和私钥凭证的 Git 步骤

使用 ssh 协议、私钥凭证和 master 分支从 git 客户端插件源仓库检出。 如果通过ssh协议访问远程git仓库，则凭证必须是私钥凭证。 如果使用 http 或 https 协议访问远程 Git 仓库，则凭据必须是用户名/密码凭据。

这Pipeline 语法片段生成器生成这个例子： 

git credentialsId: 'my-private-key-credential-id',
    url: 'git@github.com:jenkinsci/git-client-plugin.git'

示例：禁用 https 和更改日志的 Git 步骤

使用 https 协议从 Jenkins 源仓库检出，无凭据，主分支和更改日志计算已禁用。 如果变更日志是 false，则不会为此作业计算变更日志。 如果变更日志为 true 或未设置，则将计算变更日志。 请参阅工作流程 scm 步骤文档了解更多变更日志详细信息。

这Pipeline 语法片段生成器生成这个例子： 

git changelog: false,
    url: 'https://github.com/jenkinsci/credentials-plugin.git'

示例：使用 https 协议并禁用轮询的 Git 步骤

使用 https 协议从 Jenkins 平台贴标机仓库检出，无凭据，主分支，并且不轮询更改。 如果 poll 为 false，则不会轮询远程仓库以了解更改。 如果 poll 为 true 或未设置，则将轮询远程仓库以了解更改。 请参阅工作流程 scm 步骤文档了解更多投票详情。

这Pipeline 语法片段生成器生成这个例子： 

git poll: false,
    url: 'https://github.com/jenkinsci/platformlabeler-plugin.git'
