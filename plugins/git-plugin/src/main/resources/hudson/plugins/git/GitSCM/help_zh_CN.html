Git 插件为 Jenkins 项目提供基本 Git 操作， 可轮询、获取、检出和合并 Git 仓库内容。

scmGit 参数是 Git 插件的参数，可配合 Pipeline SCM 的checkout 步骤，将 Git 仓库检出到 Pipeline 工作区。 Pipeline 语法片段生成器可引导用户选择 Git 插件的检出选项，并为每项选项提供在线帮助。

使用Pipeline 片段生成器为 checkout 步骤生成示例 Pipeline 脚本。 checkout 步骤的示例包括：

  • 默认的检出步骤
  • 使用 https 和特定分支的检出步骤
  • 使用 ssh 和私钥凭证进行检出步骤
  • 禁用 https 和更改日志的检出步骤
  • 使用 Git 协议和禁用轮询的检出步骤
请参阅参数描述了解更多详情。

scmGit 参数可让 checkout 步骤使用 Git 插件提供的全部 Pipeline 功能： 

checkout scmGit(userRemoteConfigs: [
                    [ url: 'https://github.com/jenkinsci/git-plugin' ]
                ])

笔记：checkout 步骤与scmGit 参数是首选 SCM 检出方式。 对于不需要 Git 插件的所有功能的简单情况，也可以使用 git 步骤。

使用Pipeline 片段生成器为检出步骤生成示例 Pipeline 脚本。

checkout 步骤与scmGit 参数可以在许多无法使用 git 步骤的情况下使用。 请参阅Git 插件文档有关检出步骤可用选项的详细说明。 例如，checkout 步骤支持：

  • SHA-1 检出
  • 标签检出
  • 子模块检出
  • 检出稀疏
  • 大文件检出 (LFS)
  • 参考仓库
  • 分支合并
  • 仓库标记
  • 自定义 refspec
  • 超时配置
  • 针对非默认参考的变更日志计算
  • 枯枝修剪

示例：使用默认值的检出步骤

使用 https 协议、无凭据和 master 分支从 Git 插件源仓库检出。

这Pipeline 片段生成器生成这个例子： 

checkout scmGit(userRemoteConfigs: [
                    [ url: 'https://github.com/jenkinsci/git-plugin' ]
                ])

示例：使用 https 和特定分支的检出步骤

使用 https 协议、无凭据和特定分支 (stable-2.289) 从 Jenkins 源仓库检出。

这Pipeline 片段生成器生成这个例子： 

checkout scmGit(branches: [[name: 'stable-2.289']],
                userRemoteConfigs: [
                    [ url: 'https://github.com/jenkinsci/jenkins.git' ]
                ])

示例：使用 ssh 和私钥凭证的检出步骤

使用 ssh 协议、私钥凭证和 master 分支从 git 客户端插件源仓库检出。 如果通过ssh协议访问远程git仓库，则凭证必须是私钥凭证。 如果使用 http 或 https 协议访问远程 Git 仓库，则凭据必须是用户名/密码凭据。

这Pipeline 片段生成器生成这个例子： 

checkout changelog: false,
         scm: scmGit(userRemoteConfigs: [
                         [ credentialsId: 'my-private-key-credential-id',
                           url: 'git@github.com:jenkinsci/git-client-plugin.git' ]
                     ])

示例：禁用 https 和更改日志的检出步骤

使用 https 协议从 Jenkins 源仓库检出，无凭据，主分支和更改日志计算已禁用。 如果变更日志是 false，则不会为此作业计算变更日志。 如果变更日志为 true 或未设置，则将计算变更日志。 请参阅工作流程 scm 步骤文档了解更多变更日志详细信息。

这Pipeline 片段生成器生成这个例子： 

checkout changelog: false,
         scm: scmGit(userRemoteConfigs: [
                         [ url: 'https://github.com/jenkinsci/credentials-plugin' ]
                     ])

示例：使用 Git 协议并禁用轮询的检出步骤

使用 Git 协议从命令行 Git 仓库检出，没有凭据，master 分支，并且不轮询更改。 如果 poll 为 false，则不会轮询远程仓库以了解更改。 如果 poll 为 true 或未设置，则将轮询远程仓库以了解更改。 请参阅工作流程 scm 步骤文档了解更多投票详情。

这Pipeline 片段生成器生成这个例子： 

checkout poll: false,
         scm: scmGit(userRemoteConfigs: [
                         [ url: 'git://git.kernel.org/pub/scm/git/git.git' ]
                     ])
