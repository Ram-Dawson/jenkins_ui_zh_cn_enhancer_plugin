如果设置，并且 Jenkins 设置为轮询更改，则在确定是否需要触发构建时，Jenkins 将忽略此列表中用户提交的任何修订。假设构建服务器使用不同的 SCM 用户提交更改，这可用于排除构建本身完成的提交触发另一个构建。

使用此行为将妨碍更快的 git ls-remote 轮询机制，强制轮询需要工作空间，从而有时会触发不需要的构建，就好像您也选择了 使用工作空间 扩展进行强制轮询一样。

每个排除项都使用精确的字符串比较，并且必须用新行分隔。 仅当用户名与此列表中的名称之一完全匹配时才会被排除。 

auto_build_user
