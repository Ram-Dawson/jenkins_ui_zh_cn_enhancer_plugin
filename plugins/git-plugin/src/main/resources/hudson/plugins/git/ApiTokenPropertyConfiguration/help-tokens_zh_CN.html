这些访问令牌充当对 notifyCommit 端点的请求进行身份验证的方式。

默认情况下，对 notifyCommit 的所有请求都必须在 token 查询参数中包含有效令牌。但是，可以禁用 系统属性的要求： 

hudson.plugins.git.GitStatus.NOTIFY_COMMIT_ACCESS_CONTROL

它有两种模式：
  • disabled-for-polling - 允许未经身份验证的请求，只要它们仅请求轮询在 url 查询参数。禁止尝试通过提供立即安排构建的未经身份验证的请求 sha1 查询参数。
  • disabled - 完全禁用访问令牌机制并允许所有请求 notifyCommit 未经身份验证。 此选项不安全，不推荐。
