扩展添加新行为或修改现有插件行为以适应不同用途。 扩展可以帮助用户更精确地调整插件行为以满足他们的需求。

扩展包括：

  • 克隆扩展[修改将远程更改检索到代理工作区中的 Git 操作。 扩展程序可以调整检索的历史记录量、允许检索运行的时间以及其他检索详细信息。
  • 检出扩展修改将文件从代理上的 Git 仓库放入工作区的 Git 操作。 这些扩展可以调整检出操作的最大持续时间、git 子模块的使用和行为、磁盘上工作空间的位置等等。
  • 变更日志扩展针对不同情况调整源代码差异计算。
  • 标记扩展允许插件在当前工作区中应用标签。
  • 构建启动扩展控制启动构建的条件。 他们可以忽略更改通知或在轮询时强制对提交进行更深入的评估。
  • 合并扩展可以选择将其他分支的更改合并到代理工作区的当前分支中。 它们控制合并的源分支以及应用于合并的选项。
