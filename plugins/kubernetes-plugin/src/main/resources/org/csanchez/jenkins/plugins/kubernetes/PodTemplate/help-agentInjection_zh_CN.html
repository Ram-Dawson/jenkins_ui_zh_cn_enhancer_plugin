此选项允许提供不继承 Jenkins agent 镜像的 container 镜像。

提供的 container 镜像必须安装无图形界面的 JRE，且版本应与当前 Jenkins 版本兼容。

agent 将使用 JENKINS_JAVA_BIN 环境变量指定的 Java 安装；未定义时使用 PATH 中的安装。

启用此选项会覆盖 agent container 中定义的命令和参数。

示例

podTemplate(agentContainer:'foo',
            agentInjection: true,
            yaml:'''
spec:
  containers:
  - name: foo
    image: eclipse-temurin:22.0.2_9-jre
''') {
  node(POD_LABEL) {
    sh 'true'
  }
}
