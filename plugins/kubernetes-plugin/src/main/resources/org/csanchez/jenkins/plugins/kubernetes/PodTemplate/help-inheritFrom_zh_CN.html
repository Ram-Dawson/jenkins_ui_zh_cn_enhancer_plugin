要继承的 Pod Template 的名称。

Pod Template 可选择继承现有模板。这表示它会继承父模板的 node selector、service account、image pull secrets、container templates 和 volumes。

覆盖 service account 和 node selector 时，会完全替换父模板的值。

若添加到当前 Pod Template 的 container template 在父模板中有同名 container template，则会继承父 container template 的配置。
找不到匹配项时，按原样添加该模板。

Volume 继承方式与 Container Template 完全相同。

Image Pull Secrets 会合并使用，即同时使用父模板和当前模板定义的全部 Secret。

默认情况下，Pod Template 继承外层 Pod Template 定义。
可使用空字符串停止继承。
