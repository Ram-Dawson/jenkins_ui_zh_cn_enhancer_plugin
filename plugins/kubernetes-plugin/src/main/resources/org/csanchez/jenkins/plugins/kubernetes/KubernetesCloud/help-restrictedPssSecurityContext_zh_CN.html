在 Agents namespace 中结合 restricted Pod Security Standard 使用 Pod Security Admission 时，若不以 securityContext 覆盖 container 定义，jnlp container 无法被调度。

此选项会向 jnlp container 自动注入适用于 restricted Pod Security Standard 的 securityContext。

启用此选项时，jnlp container 使用以下 securityContext：

securityContext:
  allowPrivilegeEscalation: false
  capabilities:
    drop:
    - ALL
  runAsNonRoot: true
  seccompProfile:
    type: RuntimeDefault
