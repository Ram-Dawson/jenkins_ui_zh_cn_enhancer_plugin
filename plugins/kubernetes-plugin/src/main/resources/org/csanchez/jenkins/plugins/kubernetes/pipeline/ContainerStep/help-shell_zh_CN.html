指定在 container 内运行的 shell，用于处理 Jenkins 发出的运行可执行文件、设置环境变量等基础设施请求。

这不会影响运行用户代码（例如 sh step）所使用的 shell。要在 Linux 上以特定 shell 运行脚本，请使用解释器行：

sh '''#!/bin/bash
for x in {0..9}; do echo x; done
'''

或者直接使用子进程和外部版本管理的脚本：

sh 'bash ci.sh'

在 Windows 上，请选择 bat 或 powershell step。

对于在 Linux 上运行的 Pod，默认值为 sh，它应位于 $PATH 中；对于在 Windows 上运行的 Pod，默认值为 cmd，它应位于 %Path% 中。通常不应覆盖。
