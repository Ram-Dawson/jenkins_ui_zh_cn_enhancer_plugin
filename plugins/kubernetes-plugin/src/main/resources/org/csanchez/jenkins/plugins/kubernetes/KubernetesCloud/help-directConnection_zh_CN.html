启用此选项后可直接连接 TCP agent listener 端口，无需连接 HTTP(S) 端口以获取部分元数据。

该选项适用于 Controller 未暴露 HTTP(S) 端口的场景，例如 Jenkinsfile Runner；也可用于略微优化连接。

注意：在 Direct Connection 模式下，若“TCP port for inbound agents”配置为 Random，agent 无法在 Controller 重启后重新连接。
注意：Direct Connection 不支持当前提供的 jenkins/inbound-agent:windowsservercore-ltsc2022 镜像。
