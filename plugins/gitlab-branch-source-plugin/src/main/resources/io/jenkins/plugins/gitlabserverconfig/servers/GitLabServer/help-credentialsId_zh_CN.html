您可以创建自己的 个人 access token。

Token 应注册以下 scopes：
  • api - 对 API 的读/写访问权限，包括所有组和项目
  • repo - 通过 /user API endpoint 对已认证用户配置文件的只读访问权限， 其中包括用户名、公开邮箱和全名
在 Jenkins 中，将 token 创建为「GitLab Personal Access Token」或任意 「StringCredentials」类型的凭据（例如「"Secret text"」由 Plain Credentials plugin 提供，或 「"Vault Secret Text Credential"」由 HashiCorp Vault plugin 提供）。 建议使用易读的 ID 和描述。

如果您已有 GitLab 登录名和密码，可以在 GitLab Servers 的高级部分使用 「管理其他 GitLab 操作」自动将其转换为 token。
