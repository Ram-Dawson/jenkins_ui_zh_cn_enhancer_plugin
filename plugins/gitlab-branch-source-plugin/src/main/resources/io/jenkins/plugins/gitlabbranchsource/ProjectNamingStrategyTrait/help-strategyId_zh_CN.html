决定项目的命名约定。
完整项目路径
此选项会使用组和项目的完整项目路径。 示例：
  • my-group/my-project
  • my-group/other-project
  • my-group/my-subgroup/third-project
项目名称
此选项使用 GitLab 项目名称中的项目名称。 这是项目的“易读”名称，其中可以包含大小写、空格或其他特殊字符。 示例：
  • My Project
  • Other project
  • My Subgroup / Third project
上下文项目路径
此选项会使用含嵌套组的项目路径，但不包含 Jenkins 流水线中指定的顶级 owner 段。 当流水线的 owner 设置为 "my-group" 时，示例为：
  • my-project
  • other-project
  • my-subgroup/third-project
简单项目路径
此选项使用不添加父组信息的项目路径。 示例：
  • my-project
  • other-project
  • third-project
