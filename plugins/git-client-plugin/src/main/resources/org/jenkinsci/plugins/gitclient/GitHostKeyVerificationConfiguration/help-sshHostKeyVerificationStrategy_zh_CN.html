控制 Git 插件在通过 SSH 连接时如何验证主机提供的密钥。

Known hosts file (default)
使用 known_hosts 文件验证所有主机密钥。
Accept first connection
如果此前未见过该主机，则自动将其主机密钥添加到 known_hosts 文件；不允许连接到已见过但密钥已变更的主机。
注意：使用临时节点（例如云节点）时，此策略在节点上使用 known_hosts 文件，实际效果等同于 No verification。为避免此问题，可以在创建节点镜像或模板时预先配置包含所有相关主机的 known_hosts，或使用 Manually provided keys、Known hosts file 策略。
命令行 Git 使用此选项需要 OpenSSH 7.6 或更高版本。
Manually provided keys
使用在此手动配置的一组密钥验证所有主机密钥。
No verification (not recommended)
完全不验证主机密钥。
