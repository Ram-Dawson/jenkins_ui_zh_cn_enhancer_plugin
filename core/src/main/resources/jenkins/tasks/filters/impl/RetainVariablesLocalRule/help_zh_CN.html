限制哪些环境变量会被传递给构建步骤。

传递给构建步骤的环境变量会被过滤，除非它们列在下方保留名单中。

这个过滤器的行为，取决于该环境变量最初是否定义在 Jenkins 之外：

  • 如果环境变量来自 Jenkins 配置本身，例如 JOB_URL ，那么除非在这里显式指定，否则它不会被传递给构建步骤。
  • 如果环境变量来自 Jenkins 之外，例如 PATH ，其行为则取决于 进程环境变量处理方式 选项： 如果该选项设置为 保留 ，则会将原始值传递给构建步骤，而忽略 Jenkins 内部做出的修改； 如果该选项设置为 移除 ，则该变量不会传递给构建步骤。

下表展示了过滤器对环境变量的影响：

行为 最初定义在 Jenkins 之外 最初定义在 Jenkins 之内
进程环境变量处理方式： reset 变量会被重置为原始值 变量会被移除
进程环境变量处理方式： removed 变量会被移除 变量会被移除
