如果设置了该值，则对应的批处理 errorlevel 会被解释为“不稳定（unstable）”构建结果。 当最终的 errorlevel 与该值一致时，构建结果会被标记为不稳定，并继续执行后续步骤。 支持的取值范围与 Windows 类系统可表示的最宽 errorlevel 范围一致。 在 Windows NT4 及更高版本中， ERRORLEVEL 以 4 字节有符号整数保存，因此最大值和最小值分别为 2147483647 和 -2147483648 。 较旧版本的 Windows 使用 2 字节； DOS 类系统使用 1 字节，因此 errorlevel 范围为 0-255 。 值 0 会被忽略，不会将构建标记为不稳定，以保持默认行为一致。
