运行一个 Shell 脚本来构建项目（默认使用 sh ，但可以自行配置）。脚本会在工作区目录下执行。 直接在这里填写你的 Shell 脚本内容即可。 如果脚本没有类似 #!/bin/sh 这样的头部声明，那么会使用系统全局配置的 Shell； 你也可以通过头部声明改用其他语言（例如 #!/bin/perl ）或控制 Shell 的执行选项。

默认情况下，Shell 会带上 `-ex` 选项执行。 也就是说，所有命令都会在执行前先打印出来，并且只要其中任何命令以非零退出码结束，构建就会被判定为失败。 如果你想修改这一行为，可以在脚本头部使用 #!/bin/... 进行控制。

从最佳实践角度来说，尽量不要把很长的 Shell 脚本直接写在这里。 更推荐把脚本放到 SCM 中，再由 Jenkins 去调用它（例如使用 bash -ex myscript.sh 之类的方式），这样也能更方便地追踪脚本本身的变更历史。
