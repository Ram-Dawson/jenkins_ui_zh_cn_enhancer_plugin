代理节点需要有一个专门供 Jenkins 使用的目录。请填写该目录在代理节点上的路径。 最好使用绝对路径，例如 /var/jenkins 或 c:\jenkins 。 这里应当是代理节点本机上的本地路径，不需要从控制器可见。

代理节点本身不保存关键数据；所有作业配置、构建日志和构建产物都存储在控制器上， 因此理论上也可以把临时目录作为代理根目录。
不过，如果给代理节点配置一个在机器重启后不会被删除的目录，就可以缓存工具安装、构建工作区等数据。 这样在代理节点重启后再次执行构建时，可以避免重复下载工具或重新检出源码。

如果你使用相对路径，例如 ./jenkins-agent ，该路径将相对于 启动方式 提供的工作目录来解析。

  • 对于由 Jenkins 控制代理进程启动的启动器（如 SSH），当前工作目录通常比较稳定，例如用户主目录。
  • 对于 Jenkins 无法控制代理进程启动方式的启动器（如通过命令行启动的入站代理），当前工作目录在不同次启动之间可能发生变化，因此使用相对路径可能会带来问题。
    使用相对路径时最常见的问题，是代理节点上会不断累积过期的工作区和工具安装目录，从而导致磁盘空间问题。
